A web-based mock examination platform designed to provide an online exam experience with proctoring features.

Features
Online mock examinations
Exam timer
Question navigation
Auto-save functionality
Online proctoring
Browser API integration
User-friendly interface
Exam result management
Technologies Used
HTML
CSS
JavaScript
Browser APIs

How to Run
Download or clone this repository.
Open the project folder.
Open index.html in a web browser.
Purpose
This project is developed as an academic project to demonstrate an online mock examination platform with proctoring and exam-management features.
