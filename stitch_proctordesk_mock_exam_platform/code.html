EXAMINATION INSTRUCTIONS & CANDIDATE CODE

Read each regulation carefully before proceeding to the system lock verification.

  1. Strict Countdown Timer: The examination operates under a strict synchronous 30-minute timer. When the timer reaches 00:00, the terminal auto-submits all recorded responses immediately.
  2. Mandatory Fullscreen Mode: The assessment will request and lock fullscreen. Leaving fullscreen triggers a high-priority compliance warning.
  3. Tab Switching & Window Blur: Switching browser tabs or defocussing the examination tab is automatically monitored via the HTML5 Page Visibility API and logged to your dossier.
  4. Continuous Local Autosave: Every selected alternative is instantly persisted to browser localStorage. Accidental reloads or interruptions will resume your exact progress without data loss.
  5. Question Navigator: You can flag questions for later review, unflag them, and jump directly to any question using the matrix panel.
  6. Pre-Submission Review: Before final submission, a comprehensive audit screen will highlight all unanswered and flagged questions.
